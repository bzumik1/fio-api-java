# Fio API documentation

`fio-api-bankovnictvi-2025-10-16.pdf` is Fio banka's own documentation of the API ("API Bankovnictví", version of
16 October 2025, in Czech), copied here so the library can be read against the exact version it implements. The
current version is published by Fio at https://www.fio.cz/bankovni-sluzby/api-bankovnictvi.
